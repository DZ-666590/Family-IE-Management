# 投资证券搜索修复

分支：`codex/module-investment-search`，独立 worktree 基于 Stage 2 `bd9ca79`。本模块未合入或部署到线上。

## 原因与调整

- 港美股搜索以关键词作为查询缓存键，换词时暂时没有结果数据，旧实现因此把输入框设为禁用，打断连续输入；行情页存在相同问题。现在仅外部只读状态或确认证券身份时禁用，不因后台搜索禁用输入。
- 中文输入法组合文字经过250毫秒就会发出请求。新增共享输入状态，组合期间不搜索、不触发键盘选股，确认文字后再防抖查询。
- 原“记一笔投资”默认只查A股，小米属于港股范围。改为默认“全部”，并行查询A股、港股、美股，保留市场筛选和切换时的关键词；单个市场失败不会遮住其他市场结果。
- 港交所目录原来用中文显示名覆盖英文名称。现在保留官方中英文名称作为内部搜索字段，不改变公开证券数据结构、交易所、币种或证券身份。
- 港股代码查询支持补前导零、`.HK`后缀和全角数字。没有新增行情供应商、依赖或运行时配置，也不会生成假证券。
- A股目录未启用/同步中、港美股目录失败或旧缓存均显示明确状态与重试。不可用的证券结果禁止选择，但搜索输入仍可用；中文组合期间鼠标点击也不会误选股票。

## 验证

- 真实React组件测试：搜索请求未完成时继续输入`1810`，输入框保持启用及焦点，晚到响应不清空文字。
- 输入法测试：组合`xiaom`时不发出该关键词请求，确认“小米”后从默认全部市场找到`01810`，选择后核对服务器证券ID、市场和币种。
- 美国数据源失败时港股仍可搜索；切换到港股保留“小米”关键词。
- 目录测试：`小米`、`Xiaomi`、`1810`、`１８１０`、`01810.HK`均命中同一官方目录条目。
- 前端全量回归、类型检查、生产构建；行情适配器和发布安全测试分别执行。无本地业务服务器启动、无线上财务写入。

本轮结果：前端288项通过，行情适配器45项通过，发布安全25项通过；TypeScript检查和Vite构建通过（保留既有大包体积提示）。

## 边界

测试覆盖当前修复的输入行为与受控目录样本，不冒充线上新版实测。中文名称依赖上游中文目录；本次不包含全量繁简转换、拼音或所有公司的中文译名词典。上线时需同时发布前端与行情适配器，已有配对部署流程支持这一点。
