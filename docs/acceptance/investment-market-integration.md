# 投资持仓行情接入验收

## 本轮功能

- 股票目录由系统获取，不再由家庭用户创建证券名称/代码。
- 初始化选择已有持仓（OPENING）或明确空持仓；真实买入继续通过现金账本记账。
- 持仓和行情页可查看 KLineChart：日/周/月、复权方式、成交量、MA、MACD。
- 图表和估值分离；无覆盖、服务故障、缓存数据不伪装为有效最新行情。

## 部署边界

本文件记录实现与验证，不表示已经推送或部署。现有 GitHub Actions 只分发 Java JAR；首次上线必须安装 loopback 行情适配器，并配置 Java 的 MARKET_DATA_URL。适配器代码/依赖更新也必须按运行文档同步，不能只更新前端后宣称上线。

只验证过样本与本次目录快照，未证明所有股票和所有日期都覆盖，亦不承诺免费上游长期可用。课程项目的学术使用与商用再分发授权分开处理。
