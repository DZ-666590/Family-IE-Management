# 港美股只读行情：交付与验证

## 已实现

- 行情模块增加 A 股、港股、美股切换。港美股选择使用市场/代码身份，不伪造内部证券 ID。
- 港股目录读取港交所官方股本证券名单和交易币种，可使用官方中文名称；美股目录读取 Nasdaq 与其他交易所名单，排除测试证券、ETF、优先股、权证等非本轮目标证券。
- 选股后直接展示参考收盘价与 KLineChart，支持日/周/月、MA/VOL/MACD。海外目前仅使用不复权日线。
- 港美股金额带 ISO 币种，按香港/纽约交易日聚合，纽约夏令时不会改变月份边界筛选。
- 海外页面隐藏人民币持仓汇总、初始化与记账入口，不会将海外价格计入家庭资产。现有人民币记账规则不变。
- 目录准备在后台进行；前端每 5 秒检查，最多自动等待 3 分钟，之后可手动重试。错误、空结果、旧缓存分别提示。
- 搜索菜单复用已修复的同宽定位、尺寸监听和 Esc 行为，保留原 A 股测试。

## 重要数据规则与修复

1. HKEX 文件存在错误的工作表范围声明 `A1:R8`，真实内容远超此范围。读取时重置只读工作表维度，跳过标题与更新日期两行，保留实际行数和目录数量校验。
2. Nasdaq 的 `$` 系列优先股先按类型排除，再校验普通股票代码；不会因这些非目标证券阻塞整个目录，也不会跳过格式损坏的普通股票。
3. 港交所 `RMB` 标签在 Java 接口统一为 `CNY`，只变币种标签，OHLC/成交额不做换汇。
4. 美股成交额保留 null，不使用解码器默认值或收盘价乘成交量伪造。
5. SINA 港股收盘价有少量极小浮点尾差。仅对 HK 收盘价与高低边界的比较允许 `min(0.00002, max(abs(high),abs(low),abs(close))*0.0000001)`；所有原值保留，不四舍五入修补数据。开盘价、高低价关系、明显错误和低价股相对误差仍严格校验，其他市场不放宽。
6. 先剔除约 740 天窗口之外和当日未采用的数据，再校验返回窗口内的价格、成交量和重复日期，远古坏数据不阻塞当前图表。
7. Java 同时要求 K 线日期早于实际时钟与提供者抓取时间各自的市场日期，五分钟时钟偏差不能绕过跨午夜保护。
