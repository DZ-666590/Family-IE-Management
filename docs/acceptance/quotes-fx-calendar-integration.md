# 盘中报价、历史汇率与统一日历验收

## 行为与边界

- 投资持仓页可见时，交易窗口内约每 60 秒获取参考报价；页面隐藏时暂停轮询。服务端按市场共享缓存，手动刷新也不绕过限频。
- A 股、港股、美股使用固定腾讯公开报价端点，校验证券标识、币种、价格和上游时间。页面区分上游报价时间与获取时间，过时报价保留但标记延迟或缓存，不伪装实时。
- 盘中报价只用于投资页面的参考估值和用户主动填入参考价；不修改成交价、持仓成本、账本或历史快照。手工价格优先，同日或更晚的正式收盘价优先于盘中缓存。
- 休市降频按市场时区、常规交易窗口和周末计算，包含美股夏令时；尚非完整交易所节假日日历。公开服务没有实时性或可用性保证。
- 日线在市场当地收盘后留出发布缓冲再接受当天数据；缓存到跨越收盘边界时失效，不再一律排除今天。
- 历史汇率支持 30/90 天缺失区间异步补齐，失败保留已有数据并显示重试状态。现金原币余额不受补齐影响。
- 历史账务只采用确切日期或提供方确认的日期映射；不把任意较早的缓存当成缺失日期的正式汇率。已绑定记录保持不变，旧版不确定引用可见告警。
- 即使查询日期没有流水，历史报表也能触发汇率日期解析。首次响应可能仍缺值，`X-FX-Resolution` 与 `Retry-After` 表示解析状态；后续请求取得解析后的结果。
- 今天的估值可使用明确标记的最近汇率估算；历史报表和成本绑定仍走严格日期规则。
- 日期和月份输入统一为中文日历，使用现有 Semi UI 和全局配色；保留 ISO 日期字符串、必填、范围、只读及忙碌禁用规则。日历支持键盘打开、选择和 Escape 关闭。

## 复用决策

| 候选 | 判断 |
| --- | --- |
| 腾讯公开逐证券批量报价 | 选用：可限制请求规模，包含证券身份和报价时间，便于缓存与校验 |
| 东方财富候选报价接口 | 本次探测港美股时间字段不可用，未作为可信时间来源接入 |
| AKShare 全市场快照 | 不用于 60 秒逐持仓刷新，避免反复获取完整市场；已有历史日线能力保留 |
| 浏览器原生日历 | 样式与交互跨平台不可控，替换 |
| 已安装 Semi DatePicker | 选用：复用现有依赖，统一主题和表单适配，无新增包 |

## 已验证与未验证

- 2026-09-09，本机真实调用生产 Python worker 路径，沪、深、北股报价身份与时间校验成功；港股返回约 15 分钟前报价并正确标记延迟，美股收盘报价返回休市状态。这些观测不是对未来服务质量的承诺。
- Java 全量本地回归（排除 StageTwo 启动冒烟）：687 项，685 通过、2 跳过、0 失败。覆盖 H2 V38 升级、汇率、报表及报价边界。
- Python 行情适配器 53 项、部署安全 25 项通过；部署测试输出来自夹具，不代表实际部署。
- 前端最终验证：52 个测试文件、305 项通过，类型检查和生产构建成功；日历覆盖时区、键盘、校验及抽屉关闭行为。构建仍提示部分包超过 500 kB，属于待拆包优化项，不是构建失败。
- 本轮未启动本地业务服务，未完成新代码的线上浏览器验收；共享 SSH 尚不可用，不能把本机供应商可达视为云端可达。
- MySQL V38 脚本已提供，尚未在生产 MySQL 执行。模块分支交付不等于 Stage2 合并或上线。
