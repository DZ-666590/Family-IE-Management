# 账户分类图标来源

支付宝和微信图标路径取自 Simple Icons，2026-09-08 获取：

- https://github.com/simple-icons/simple-icons/blob/develop/icons/alipay.svg
- https://github.com/simple-icons/simple-icons/blob/develop/icons/wechat.svg
- 项目许可：https://github.com/simple-icons/simple-icons/blob/develop/LICENSE.md （CC0 1.0）

仅用于标识用户手工维护的账户类别，不表示官方关联、授权、支付连接或品牌背书；商标权不因 CC0 而转让。图标以静态 SVG 路径随前端打包，不插入外部 HTML，不向外部发送账户信息。

现金、银行和其他钱包沿用现有 lucide-react 图标。
