# 系统共享 AI 服务（Qwen 3.8 Max）

2026-09-09 的用户决策替代此前个人密钥方案：所有有效登录用户使用服务器统一配置的阿里云百炼 `qwen3.8-max`。个人账号不再填写地址/模型/密钥。服务器设置步骤见 [百炼服务器配置](../operations/system-ai-setup.md)。

## 已实现边界

- 设置页仅展示服务商、固定模型、服务器是否配置完成，以及明确确认后的模型目录测试。状态读取不联网，密钥和地址都不返回前端。
- `GET /api/me/ai-settings` 返回 provider/model/ready/dailyRequestLimit。ready 仅代表服务器配置格式有效，不能证明密钥有效或模型已开通。
- `POST /api/me/ai-settings/test` 需登录、CSRF 和 `{ "confirmed": true }`，只请求官方 `/models`。HTTP 页面可使用，因为此请求没有 API 密钥或文档内容；目录成功不能证明推理可用。
- 旧 PUT/PATCH/DELETE 个人配置接口返回 405 `AI_SERVER_MANAGED`。旧个人密钥存储类/表为兼容历史迁移保留，不被共享调用服务读取，也不暴露管理入口；不自动删除旧数据。
- 统一 Java 边界仍为 `AiGateway.complete(Authentication, Prompt)`，身份必须来自服务器当前会话。Prompt 支持明确批准的文字与最多 4 张 PNG/JPEG 文档页；每张最多 2 MB，总计 6 MB，单图最多 2000 万像素。图片由内存读取并编码内联 data URI，不读取远程图片 URL，也不通过 ImageIO 磁盘缓存保存图片。
- 固定非流式、关闭思考模式、最多 4096 输出 token。模型输出必须以 `finish_reason=stop` 完整结束，否则拒绝返回不完整结果。文字最多 8000 字符。返回内容仅为文本，不执行工具、不写财务数据。

**stage2 已有 Word/PDF 文本层上传和规则提取功能，本次保留原行为；该功能尚未接入 Max。** 后续接入需要处理扫描页/PDF 转图，获得外部处理确认，再调用本接口，并提供原文页码与人工核对。文档上传走 HTTP 时仍是明文传输；服务器持有密钥并不能解决上传内容的传输安全。

## 配置与安全

服务器环境：`DASHSCOPE_API_KEY`、`APP_AI_BASE_URL`。固定模型 `qwen3.8-max`。北京工作空间地址格式为 `https://<WorkspaceId>.cn-beijing.maas.aliyuncs.com/compatible-mode/v1`；也接受官方旧北京域名。只接受这些官方 HTTPS 域名及固定路径，拒绝用户信息、query、fragment、端口覆盖和其他第三方域名。具体地址以百炼控制台为准：[官方兼容 API 文档](https://help.aliyun.com/zh/model-studio/compatibility-of-openai-with-dashscope)。

密钥仅存在于服务器环境和当前外部请求，凭据对象 toString 固定脱敏。空/非法配置返回 `AI_SYSTEM_NOT_CONFIGURED` 503，其他业务与登录不受影响。无需配置旧方案的 `APP_AI_ENCRYPTION_KEY`。

复用实际建连的公网 DNS 校验、TLS 主机验证、禁止跳转/自动重试/系统代理、64 KiB 响应上限及连接/读取/取消超时（连接 5 秒；目录读取/取消 10/20 秒；文档推理读取/取消 60/90 秒）。DNS 有固定 4 线程、零排队隔离，调用者最多等待 3 秒且受请求截止时间约束。禁止日志或 APM 采集密钥/请求体；Apache wire/header logger 默认关闭。底层异常、供应商原始错误正文和密钥回显均不向用户暴露。

## 费用限制

目录测试与推理共同计数：每用户每 30 秒最多一次、每日最多 20 次；每进程每日总计最多 200 次、最多 4 个并发。日期使用应用时钟时区（默认上海）。发送失败也占一次额度，不自动重试。限额为单进程内存计数，服务重启会重置，多实例不共享；这不是人民币账单硬上限。还应在百炼控制台设置可用的费用预警/限额并检查账户余额。
