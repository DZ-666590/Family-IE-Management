# 提前还款修复验收（2026-09-07）

## 原因与修复

- 提前还款按钮先选中贷款，再调用 `crypto.randomUUID()`。该 API 仅在安全上下文提供，普通 HTTP 访问会抛错；已更新的选中状态因此误展示还款计划，而非提前还款表单。改用 HTTP 同样可用的 `getRandomValues` 生成 128 位不透明幂等键，生成成功后才切换表单状态；失败重试保留原键。
- 未来期次显示“未到期”，说明提前偿还本金应走贷款卡片的提前还款入口；未放宽后端按期确认的到期限制。
- 连续部分提前还款时，旧实现累计已取消的历史期次导致剩余期数增长。改为取消前读取当前待还期数，再按原策略重排；保留已付、已取消历史和幂等行为。不批量重写既有贷款历史。

API 兼容性参考：[randomUUID 安全上下文限制](https://developer.mozilla.org/en-US/docs/Web/API/Crypto/randomUUID)、[getRandomValues](https://developer.mozilla.org/en-US/docs/Web/API/Crypto/getRandomValues)。

## 证据

- 修复前前端回归复现 `crypto.randomUUID is not a function`，提前还款表单未打开；未来期次错误提供确认按钮。
- 修复前后端回归：第二次部分提前还款应剩 2 期，实际变成 4 期。
- 修复后前端 131 项测试、类型检查和生产构建通过。新增回归覆盖 HTTP 缺少 randomUUID、正确提交端点、失败重试幂等键保持、未来期次不提供确认操作。
- 相关后端 7 项测试通过：提前还款、贷款 API、按期还款 API、计划持久化。验证连续部分提前还款剩余 2 期、准确扣减本金、幂等重试和最终结清。
