# 港美股只读行情扩展设计

## 已确认目标

在投资模块中增加港股、美股的股票搜索、参考收盘价和 K 线。保留现有 A 股与 Clarity 视觉系统。第一阶段不支持港美股持仓记账、真实下单、换汇或跨币种净资产汇总。

## 接入边界

- 海外股票使用 `market + symbol` 标识，例如 `US/AAPL`、`HK/00700`；不是内部证券数据库 ID。
- 海外目录与行情只进入独立缓存，不写入 `securities`、`investment_trades`、报价快照或现金账本。
- 现有 A 股 `/api/securities/*` 与记账校验保持不变。海外数据源故障不阻止 A 股目录同步。
- 原投资账户仍仅支持人民币。港美股页面不显示买入、卖出、期初持仓或手工估值入口。
- 股票来自可验证目录。目录不可用时显示失败和重试，不允许任意文本冒充已上市证券，不以示例名单假装完整市场。

## 数据源选择：复用优先

| 候选 | 证据与约束 | 决定 |
|---|---|---|
| AKShare / 新浪日线 | 已安装依赖，服务器苹果与腾讯原始日线样本成功；免费公共网页数据没有可用性承诺 | 首选验证路径；按样本与目录覆盖逐步启用 |
| 富途 OpenAPI | 官方支持港美股行情、历史 K 线；需符合账户权限与额度 | 后备，不要求用户现在开户或购买权限 |
| Longport OpenAPI | 官方 SDK 支持港美股 K 线；需要应用凭据与权限 | 后备，接入前另行确认凭据和授权 |
| Twelve Data | 提供包括香港市场的 EOD 数据，具体覆盖与额度依套餐 | 后备，不默认免费套餐包含全部市场 |

## 接口与职责

Python 行情适配器新增独立海外模块；Java 提供需要登录和家庭成员权限的只读代理，浏览器不直连行情供应商。

- `GET /api/overseas-market/search?market=HK|US&q=...`：返回最多 20 条匹配项、是否还有结果、目录更新时间和缓存状态。
- 每个匹配项包含 `symbol`、`name`、`market`、`currency`、`exchange`、`timezone`。港股交易币种必须来自目录元数据，不能把所有香港上市证券一律假设为港币。
- `GET /api/overseas-market/candles?market=HK|US&symbol=...`：返回固定不复权日线以及标的元数据、`source`、`asOf`、`fetchedAt`、`stale`、`supported`、`bars`。
- 单根日线包括 `timestamp/open/high/low/close/volume`；上游没有提供的成交额使用 `null`，不能伪造零值或用收盘价乘成交量替代。
- 服务器验证市场枚举、代码格式、目录身份和响应元数据；参数不接受任意 URL。
- 搜索限长、结果数量有界；拉取设置超时和并发上限，同标的请求合并，缓存有界。缓存回退明确显示旧数据日期，超过保留期限直接返回不可用。

## UI 与时间、金额口径

- 行情顶部增加 A 股、港股、美股市场切换；切换时清除不匹配的选择和旧报价，保留上一市场的选择可由各市场独立状态恢复。
- 沿用同宽定位的搜索列表，名称、代码、交易所分层显示。选股后直接显示参考价和 K 线。
- 海外行情金额明确显示 ISO 币种，例如 `USD 319.97`，不复用固定人民币符号的账本格式化函数。
- 香港按 `Asia/Hong_Kong`，美国按 `America/New_York` 处理交易日和夏令时，周/月聚合使用市场交易日，不使用浏览器本地日期或固定美东偏移量。
- 第一阶段提供日、周、月 K、MA、VOL、MACD；海外仅显示不复权，不把未知复权口径冒充前复权。原 A 股前复权功能不变。
- 丢弃尚未结束的当日交易数据，参考收盘价取最近返回的完整交易日；显示日期，不声称最新交易日一定已覆盖。
- 海外页面固定说明“只读行情，暂不计入家庭资产”。

## 已完成的可行性检查

2026-09-08 在服务器执行临时只读进程：

- AKShare 版本 1.18.88。
- `stock_us_daily(AAPL, adjust='')` 返回日线，末条为 2026-09-04，收盘 319.97。
- `stock_hk_daily(00700, adjust='')` 返回 5467 条日线，末条为 2026-09-07，收盘原始值 438.39999，展示需格式化为两位小数。
- 原始 MiniRacer 与 `MemoryDenyWriteExecute=yes` 不兼容。使用 `--jitless` 后基础执行通过；腾讯日线在相同内存保护和正式低权限用户的临时进程中也成功。
- 不关闭正式服务安全限制；实现时仅解析数据，不对来自上游的文本调用 Python `eval`。美股高层封装即使请求不复权也读取复权因子，不能直接不加审查地搬入生产。
- 以上是样本可用性与解析器兼容性检查，不是完整目录验证，也不是正式页面集成或部署证明。

## 实施验收要求

1. 首先验证两市场目录字段、分页完整性、币种和代码映射；目录失败不可发布空目录替代旧目录。
2. 单元测试覆盖代码校验、非有限价格、OHLC 范围、重复日期、缺失成交额、缓存过期、市场间隔离与美东夏令时。
3. Java 接口测试覆盖未登录/非成员拒绝、参数校验、错误转换；确认海外请求不会创建任何账务记录。
4. 前端测试覆盖市场切换后不残留旧股票、币种显示、日周月聚合、无写入入口、失败重试及 A 股原功能回归。
5. 使用云端隔离预览验证实际样本、下拉框定位和窄屏；不启动本地业务应用、不改生产数据。
6. 发布时分别更新行情适配器与 Java/前端。当前 CI 只发布应用 JAR，不能把推送 JAR 当作适配器已更新。
