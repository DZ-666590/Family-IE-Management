# 登录后账户初始化引导

## 行为

- 登录、注册后的自动登录或刷新恢复会话进入工作区时，读取当前家庭全部有效现金账户，包含分页后的账户。
- 尚未确认期初余额或缺少起始日期时显示引导；余额为零但已确认的账户不提示。
- 所有者和管理员点击“去初始化账户”进入“收支明细 → 账户”，沿用既有确认表单；普通成员提示联系管理员，并可查看家庭成员。
- 引导本身只读取数据、进行导航，不填入真实金额，不确认期初余额，不发送财务写请求。
- 可选择稍后处理，Escape 和点击背景同样关闭。同一次工作区访问切换模块或刷新账户数据不重复弹出；重新登录或刷新恢复会话会重新检查。
- 已在账户设置页、检测失败、没有有效账户或已有其他编辑/付款弹窗时，不额外覆盖页面。原有账务校验仍执行，关闭引导不等于完成初始化。
- 用户或家庭变化时隔离提示状态与查询；旧会话的迟到响应不影响新会话。
