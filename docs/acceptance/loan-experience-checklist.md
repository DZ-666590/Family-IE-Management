## 用户需求与验收边界

| 需求 | 必须观察到的行为 | 状态 |
| --- | --- | --- |
| 本次贷款购买物 | 自动建立同家庭资产；默认分类名和编号；购入价值、当前价值等于本金；一笔资产/贷款分录，不制造现金 | 通过 |
| 计划金额 | 原有剩余本金旁显示当前计划还款总额、剩余还款总额；实际已付金额包含本金和利息，取消期次不重复统计 | 通过 |
| 一键结清 | 先展示本金、应付利息和付款账户，再一次原子提交；结清后本金归零、未来计划取消，已付历史保留 | 通过 |
| 账户现金 | 指定账户独立验证余额；不能使用其他账户或非现金资产补足；不足时本金、现金、计划和流水均不改变 | 通过 |
| 两种部分提前还款 | 用户选择缩短期限或减少还款额，提交前比较变化；后台重算与预览一致，保留原到期日和历史 | 通过 |

本系统同步人工录入的账务，不替代银行扣款。页面上的“结清”记录账内结清；实际银行利息、费用及合同限制需要用户核实。

## 关键数字案例

- 计划本金 2,000 元，已到期未付利息 100 元，未来计划利息 50 元：当前计划总额为 2,150 元，账内结清预览为 2,100 元。不能把未来 50 元自动收取，也不能略过已到期的 100 元。
- 指定账户只有 2,099.99 元，即使另一个账户有钱或拥有高价值资产，也必须结清失败；资金恰好 2,100 元时，成功后该账户与贷款本金均归零，利息费用为 100 元。
- 零息贷款原剩余本金 1,200 元、12 期，提前还本 300 元：缩期得到 9 期、每期 100 元；减供得到 12 期、每期 75 元。
- 等额本息原本金 1,200 元、年利率 12%、12 期，原常规每期 106.62 元。提前还本 300 元后，缩期应为前 8 期各 106.62 元、尾期 92.06 元；减供应为前 11 期各 79.96 元、尾期 80.00 元。

## 设计取舍

| 选择 | 原因与代价 |
| --- | --- |
| “本次贷款购买物”按贷款方直接支付卖方记账 | 避免虚构现金进出；款项实际先到账再购买时，使用已有放款和购买流程 |
| 房产、车辆的未知资料保留待完善状态 | 不编造面积、地址或车型；用户之后需要补齐真实资料 |
| 当前计划总额为实际已付现金加有效待还本息 | 提前还款后数字会更新，不是不可变的原合同总额；银行实际计息仍需核实 |
| 结清默认包含已到期未付利息，不包含未来计划利息 | 避免多收或免除已到期利息；支持填入更高的实际利息，不声称是银行报价 |
| 部分提前还款前先处理已到期未付期次 | 避免重算时静默免息；需要先完成这些还款 |
| 自定义计划按原期次隐含利率和本金权重计算 | 保留自定义模型和日期；特殊合同需要人工核实，过小剩余本金不能强行分成零本金期次 |
| 标准每期利息只在最终整数分舍入一次 | 修复月利率中间截断导致的半分钱错误；新建或重算的边界期次可能较旧算法相差一分，既存和已付历史不回写 |
| 默认显示当前待还计划，已付/取消期次另切历史视图 | 避免新计划被大量取消期次遮住；历史需要多切换一次，旧记录不删除，旧 API 默认行为不变 |
| 固定期限无法维持原标准还款结构时明确拒绝 | 不把等额本息暗改成等额本金；几乎全额提前还款后的极小余额，可能需要改选缩期或结清 |
