# 投资持仓行情接入验收

## 本轮功能

- 股票目录由系统获取，不再由家庭用户创建证券名称/代码。
- 初始化选择已有持仓（OPENING）或明确空持仓；真实买入继续通过现金账本记账。
- 持仓和行情页可查看 KLineChart：日/周/月、复权方式、成交量、MA、MACD。
- 图表和估值分离；无覆盖、服务故障、缓存数据不伪装为有效最新行情。

## 跟进改版：连续的投资操作体验

本轮借鉴资产选中状态贯穿行情和操作的组织方式，保留家账 Clarity 视觉系统，不提供真实委托、撮合或实时盘口。

- 搜索结果以证券名称为主，代码和交易所为辅；正常状态不再常驻目录说明和更新时间，失败仍有原因与重试。
- 修复自定义弹层容器缺少定位基准造成的严重偏移。输入框容器提供相对定位；监听其尺寸，覆盖组件内部缓存的最小宽度并重新定位。
- 展开结果时按 Escape 只关闭结果；再次按 Escape 才进入原抽屉关闭/草稿保护流程。
- 行情搜索选股后直接显示 K 线，不再要求额外点击；持仓证券名称进入同一行情页，已选证券在记账抽屉关闭后保留。
- 持仓行提供记录买入/卖出，带入证券和投资账户；行情旁也能发起记录。只有一个投资账户时默认选中，不在多账户之间猜测。
- 买入/卖出为主操作，期初持仓、分红、费用归入次级业务。成交价仍由用户确认，参考收盘价不会自动填入。
- 新记录在提交前检查已知现金余额与账内持仓，数量使用四位小数整数单位，现金复用现有精确分单位计算。卖出费用超过收入时仍校验净现金流出；期初持仓不受现金账户条件约束。历史更正继续交由原交易冲回和服务端规则核对，不套用新交易余额算法。
- 保存后沿用统一写后刷新机制更新资金、持仓和记录，避免额外并发刷新；行情失败不重放记账。
