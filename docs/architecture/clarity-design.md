# 家账 Clarity 页面设计

本次在单栏分组导航上统一各工作区页面，参照 Huzaifa Anas 的 Clarity 构图（仅作设计参考，不复制商标或示例数据）。

- 参考：https://dribbble.com/shots/24486271-Personal-Finance-Dashboard
- 图标：https://lucide.dev/guide/react ，使用 lucide-react 固定版本的内联 SVG，保留包内许可证。
- 基础组件：https://semi.design/en-US/basic/button ，复用现有 Semi Design 按钮和表单能力。

视觉：暖白画布 #F7F8FA、白色面板 #FFFFFF、墨色数字 #20272E、灰色辅助文字 #67727E、蓝色强调 #4B6BEE、绿色收入 #31846A；支出用中性蓝灰，危险操作单独用红色。中文使用系统无衬线，金额用等宽数字，标题和金额承担层级，不添加装饰性卡片。

布局：净资产大数字与历史轨迹为首屏主区域；月度收入支出及结余在右侧，现金流和近期流水为第二层，预算和提醒为辅助区域；原有细节保留在可展开区域。列表页以工具栏和表格为主体。所有财务数字和图表来自现有 API；当前净资产与所选月份现金流分别标注。

组件：统一页面头、进度、标签、空状态 SVG、错误信息、抽屉和确认框。弹层支持 Escape、焦点限制/恢复、背景滚动锁定；嵌套弹层只关闭最顶层。绘图零值不虚增高度，负值在零线下，时间序列先排序；提供可读数字和表格。

实施范围：总览、收支、账户分类、预算、周期账单、资产、投资、贷款、提醒、家庭设置及年度统计。保持现有权限与业务 API，不扩展交易能力或引入虚构指标。图标与数据图均随应用打包，无运行时 CDN 依赖。
